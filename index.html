Abstract

Large language models (LLMs) can now operate professional CAD software, yet most Agentic CAD systems either generate intermediate modeling code like CadQuery or emit low-level API calls one by one. The former struggles to generate complex CAD models in a single pass, whereas the latter creates long-horizon tasks in which errors readily accumulate. To overcome these limitations, we present Workflow-CAD, a closed-loop agent whose action space consists of engineer-level workflows extracted from professional CAD modeling videos and feature trees. We compare the Atomic API and Workflow interfaces under a controlled protocol and find that the latter significantly outperforms the former. We also introduce Workflow-CAD-Bench, a holistic Agentic CAD Modeling benchmark spanning text-to-part generation, CAD reconstruction from three-view drawings, and generation of complex, physically-plausible and kinematically-valid assemblies. Beyond comparing Agentic CAD Modeling systems, Workflow-CAD-Bench also evaluates the underlying LLMs' ability to use tools and perform autonomous modeling.
